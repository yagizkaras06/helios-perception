# Media

| File | Content |
|---|---|
| `demo/demo.gif` | short loop shown at the top of the README (keep < 10 MB) |
| `demo/demo.mp4` | the full 20-30 s demo clip |
| `screenshots/overview.png` | 3D view: point cloud, tracked objects, status panel |
| `screenshots/multi_object_tracking.png` | top-down view with several tracked objects |
| `screenshots/collision_warning.png` | an object coming at the sensor and the warning |
| `diagrams/architecture.svg` | data flow, generated by `tools/diagrams/make_architecture.py` |

Rules for media in this folder:

* Real Helios 32 data only (live or recorded) or clearly labelled synthetic data. Media are not
  edited beyond cropping and scaling.
* Every value visible in a picture is what the software published at that moment.
* No personal data: no faces or names, and no host names, IP addresses or file paths in
  terminal or window titles.
