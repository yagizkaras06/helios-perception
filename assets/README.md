Source: live RoboSense Helios 32, engineering RViz profile, screen recording of 2026-11-24 (36 s)
and one screenshot. Processing: crop to the 3D view and a horizontal flip that undoes the mirrored
RViz camera of that recording; the GIF is subsampled to 5 fps and 48 colours.

Rules for media in this folder:

* Real Helios 32 data only (live or recorded) or clearly labelled synthetic data. Media are not
  edited beyond cropping and scaling.
* Every value visible in a picture is what the software published at that moment.
* No personal data: no faces or names, and no host names, IP addresses or file paths in
  terminal or window titles.
